# Havatai Admin Panel

**Havatai Admin Panel** is a centralized management dashboard built to control and monitor the Havatai live streaming and social entertainment platform.

The admin panel enables platform administrators to manage **users, live stream activity, creators, gifts, reports, content, transactions, and overall platform operations** from one secure and organized system.

## Key Features

### Admin Dashboard
- Centralized overview of platform activity
- Monitor users, live sessions, engagement, and system performance
- View key operational data in one place
- Designed for smooth platform management

### User Management
- View and manage registered users
- Monitor user profiles and account activity
- Update user status when required
- Support safe and controlled platform operations

### Live Stream Management
- Monitor active and previous live sessions
- Track host and viewer activity
- Review live room details and engagement
- Support moderation of live streaming content

### Creator & Host Management
- Manage streamers, creators, and hosts
- Review creator activity and performance
- Support creator-based platform operations
- Help maintain quality across live sessions

### Gift & Coins Management
- Manage virtual gifts and coin-related activity
- Track gifting flow across live sessions
- Monitor user balances, transactions, and engagement
- Support monetization-related platform control

### Chat & Content Moderation
- Review reported users or content
- Support moderation of chats, profiles, and live activity
- Help maintain a safe and respectful community experience

### Reports & Complaints
- Manage user reports and complaints
- Review flagged activity
- Take action on policy or community issues
- Maintain platform trust and safety

### Reels & Content Management
- Monitor uploaded short-form content
- Review content activity and engagement
- Manage visibility when required
- Support entertainment content quality control

### Analytics & Activity Monitoring
- Track platform usage and engagement
- Monitor user growth and live activity
- Review high-level operational metrics
- Support data-driven admin decisions

## Technology Stack

- **Flutter Web & Dart** — Web-based admin panel development
- **Firebase / Backend Integration** — User, content, and platform data management
- **Live Streaming Management System** — Monitoring live sessions and creator activity
- **Gift & Coins Management Module** — Virtual gifting and transaction oversight
- **Reporting & Moderation System** — User safety and content control
- **Analytics Dashboard** — Platform activity and operational insights

## Project Highlights

- Complete admin panel for a live streaming platform

## Project Overview

Havatai Admin Panel was developed to provide administrators with complete control over the Havatai live streaming ecosystem. It helps manage users, creators, live rooms, virtual gifts, reports, content, and operational activity through a clean and centralized dashboard.

This project demonstrates expertise in building **admin dashboards, live streaming management systems, moderation tools, transaction monitoring modules, and scalable platform control panels**.
